# Pizza Dough Calculator — Color Palette Guide

## Grounds

| Token           | Hex       | Usage                                      |
|-----------------|-----------|--------------------------------------------|
| Page background | `#F5F0E8` | Main page ground — warm cream              |
| Card / Paper    | `#FFFCF5` | Panel and card surfaces                    |
| Dark surface    | `#2C1F14` | Dough Ball hero card background            |

## Brand / Interactive

| Token        | Hex       | Usage                                                  |
|--------------|-----------|--------------------------------------------------------|
| Primary      | `#B85C2A` | Slider, selected toggle, accent chip — terracotta      |
| Primary dark | `#9E4D22` | Primary hover state                                    |
| Warm gold    | `#F5C896` | Large dough ball number on dark surface                |

## Text

| Row hover        | `rgba(74,55,40,0.04)`       | Ingredient table row hover         |

## Palette Character

All colors derive from two base hues:

- **Warm brown** (`#2C1F14` / `#4A3728`) — text, borders, and structural elements
- **Terracotta** (`#B85C2A`) — all interactive and accent elements

Cream grounds (`#F5F0E8`, `#FFFCF5`) keep the interface light and editorial
without clinical white. The dark hero card (`#2C1F14`) provides contrast for
the most important value in the UI.
